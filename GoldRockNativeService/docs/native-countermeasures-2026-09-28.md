# Native-service countermeasures reviewed 2026-09-28

These three guides add conditional consumer questions to the local matching catalog. They do not determine eligibility, account liability or a legal deadline. The source registry expires them on 2026-12-27 unless reviewed again.

## Medicaid for care before an application

[Medicaid.gov's eligibility policy](https://www.medicaid.gov/medicaid/eligibility-policy) says benefits may cover up to three months before the application month when the person would have been eligible then. The state must decide the effective period and service coverage. The guide asks for the application date, service dates, state decision and processed claim; it does not treat the three-month window as an approval.

Countermeasure: request the earlier-month eligibility determination from the state, then ask the biller about claim submission only after coverage for that period is confirmed.

## Access to existing billing and claim records

[HHS guidance for individuals](https://www.hhs.gov/hipaa/for-individuals/medical-records/index.html) says HIPAA-covered providers and plans generally must allow access to existing medical and billing records and cannot deny a copy because care remains unpaid. It also describes the separate right to request amendment. [HHS access guidance](https://www.hhs.gov/hipaa/for-professionals/privacy/guidance/access/index.html) clarifies the designated record set and response process. The guide requests existing records, without claiming a right to a newly created analysis or bill correction.

Countermeasure: name the existing ledger or claim record, retain the access request and response, and compare the record with the disputed amount.

## Stop-contact request versus collector dispute

[CFPB guidance](https://www.consumerfinance.gov/ask-cfpb/how-do-i-get-a-debt-collector-to-stop-contacting-me-en-1411/) distinguishes a written request to stop an FDCPA-covered collector's contact from a timely written dispute of the debt. It says a stop-contact request does not erase a debt or prevent other lawful collection, including a possible lawsuit. A collector can send narrow notices about stopping contact or lawful action.

Countermeasure: inspect the validation notice and decide whether to dispute promptly, then send and retain a separate stop-contact request if desired. Track any court papers independently.
